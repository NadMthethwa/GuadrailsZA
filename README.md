# GuardRail SA

Content-layer scam detection API for South African SMS and WhatsApp messages.

## Getting started with Claude Code
1. Unzip this folder and open a terminal in it.
2. `git init && git add . && git commit -m "Project brief"`
3. Add your anonymised messages to `data/labelled/messages.jsonl` (delete the example line).
4. Fill in `official_senders` in `data/brands.yaml` and confirm each value.
5. Run `claude` and paste the prompt from `KICKOFF_PROMPT.md`.

Claude Code reads `CLAUDE.md` automatically every session.
